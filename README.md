# KTRP 초기 레이팅 설문 · 7.5+ 척도

한국어 모바일 우선 웹사이트. 대회·구력 → 수행능력 22문항(5영역, 스트로크 6문항·나머지 영역 각 4문항) → 선수경력 → 현재 활동 → 결과. 내부 소수점 레이팅과 공개 0.5 단위 등급, 점수별 근거, 잠정(P) 상태를 표시합니다. 답변은 브라우저 메모리에서만 처리하며 새로고침 시 초기화됩니다.

## 실행 방법

### 1. 준비

Node.js 20 이상(npm 포함)과 Python 3가 필요합니다. 터미널에서 설치 여부를 확인합니다.

```bash
node --version
npm --version
python3 --version
```

이 프로젝트에는 설치할 외부 의존성이 없으므로 `npm install`은 필요하지 않습니다.

### 2. 프로젝트 폴더에서 실행

macOS 터미널 또는 VS Code의 터미널을 열어 다음 명령을 실행합니다.

```bash
cd /Users/bangsc/Desktop/01_BSC/03_Coding/07_tennis_ktrp
npm start
```

`npm start`는 원본 코드를 `dist`에 빌드한 뒤 로컬 서버를 시작합니다. 서버가 실행 중인 동안 터미널을 열어두세요.

브라우저에서 다음 주소를 엽니다.

[http://localhost:4173](http://localhost:4173)

서버를 종료하려면 실행 중인 터미널에서 **Ctrl+C**를 누릅니다. HTML 파일을 직접 더블클릭하지 말고 서버 주소로 접속해야 JavaScript 모듈이 정상적으로 로드됩니다.

### 3. 코드를 수정한 뒤 확인

질문은 `src/data/questions.js`, 점수와 가중치는 `src/data/config.js`, 스타일은 `src/styles/main.css`에서 수정합니다. `dist`는 자동 생성 파일이므로 직접 수정하지 않습니다.

현재 실행 방식에는 자동 빌드나 자동 새로고침이 없습니다. 수정 후 서버를 Ctrl+C로 종료하고 다시 `npm start`를 실행한 다음 브라우저를 새로고침하세요.

서버를 계속 실행해두고 **다른 터미널**에서 다음 명령으로 빌드해도 됩니다.

```bash
npm run build
```

빌드가 완료되면 브라우저를 새로고침합니다.

### 테스트 및 배포 파일 생성

프로젝트 폴더에서 실행합니다.

```bash
# 계산과 설문 진행 테스트
npm test

# 배포 파일 생성
npm run build
```

빌드 결과인 `dist` 폴더 전체를 정적 웹 호스팅에 올리면 됩니다. HTML뿐 아니라 JavaScript·CSS와 하위 폴더 구조도 함께 유지해야 합니다.

### 실행에 문제가 있을 때

- `node`, `npm`, `python3` 명령을 찾을 수 없으면 해당 프로그램 설치 후 터미널을 다시 여세요.
- `package.json`을 찾을 수 없으면 위 프로젝트 폴더로 이동했는지 확인하세요.
- 4173 포트가 사용 중이면 기존 서버를 종료하거나, 빌드 후 다른 포트로 실행하세요.

```bash
npm run build
python3 -m http.server 4174 --directory dist
```

다른 포트로 실행했다면 [http://localhost:4174](http://localhost:4174)로 접속합니다.

## Base

현재 대회 실적 → 테니스 선출 → 구력 순으로 하나를 사용하며 중복 가산하지 않습니다. 대회는 최근 2년 대표 기록 하나, 복식 참가 규모(단식은 참가자 수)를 선택합니다. 16·32·48·64·96팀 이상 중 선택하며, 96팀 이상은 실제 팀 수를 추가로 묻지 않고 96팀으로 고정 계산합니다.

Tournament Base = 앵커 + 성적계수 × log2(앵커성적 / 입력성적) + 규모계수 × log2(입력팀수 / 앵커팀수).

| 유형 | 앵커 | 팀수 | 성적 | 성적계수 | 규모계수 |
|---|---:|---:|---:|---:|---:|
| 테린이 | 2.50 | 48 | 8강 | 0.25 | 0.16 |
| 지역 신인부 | 3.50 | 48 | 16강 | 0.25 | 0.14 |
| 전국 신인부 | 4.50 | 96 | 16강 | 0.25 | 0.10 |
| 오픈부 | 5.75 | 64 | 16강 | 0.30 | 0.14 |
| 지도자부 | 6.50 | 32 | 8강 | 0.30 | 0.12 |
| 실업선출 대회 | 7.50 | 32 | 8강 | 0.30 | 0.12 |

우승=1, 준우승=2, 4강=4 등. 예선/첫 경기 탈락은 전체팀 수를 사용합니다. 상위 비율은 진출 인원 / 전체팀수이며 정확한 공동순위가 아닙니다. 부전승·조별리그·상대 수준은 MVP에서 미반영입니다.

전국 96팀: 16강 4.50, 8강 4.75, 4강 5.00, 준우승 5.25, 우승 5.50. 오픈 64팀: 16강 5.75, 8강 6.05, 4강 6.35, 준우승 6.65, 우승 6.95. 대회 규모에 따라 이 값에서 연속 보정됩니다.

구력 Base: 6개월 미만 1.2 / 6~12개월 1.6 / 1~2년 2.1 / 2~4년 2.6 / 4~7년 3.1 / 7년 이상 3.4.

테니스 선출 Base: 초등 4.0 / 중등 5.0 / 고등 6.0 / 대학 7.0 / 실업·프로 7.5. 선수경력만으로 산출하는 초등 선출은 최종 5.5까지, 대회 기록이 있으면 그 상한을 적용하지 않습니다. 은퇴 후 경과와 실제 테니스 공백을 구분하여 이중 감점하지 않습니다.

## 수행능력 22문항 점수

일반 대회 미경험자 총 ±1.70 유지. 대회 경험자는 ±0.50, 무대회 초·중·고·대학 선출 ±1.20, 실업·프로 선출 ±0.80. 대회 기록이 있으면 ±0.50 우선.

보정 = Σ (답변계수 × 영역비중 × 영역 내 문항비중 × 해당 보정폭).

화면 1~5단계 답변계수: −1.00 / −0.55 / 0 / +0.45 / +1.00. 중립은 3단계이며 상위 두 단계의 차이를 넓혀 반복 가능한 높은 경기력을 더 구분합니다. 모두 1단계면 −1.70, 모두 5단계면 +1.70입니다.

| 영역 | 영역비중 | 4문항 순서대로 영역 내 비중 | 일반인 영역 최대 보정 |
|---|---:|---|---:|
| 스트로크 | 28% | 낮은 공 16%, 높은 공 16%, 찬스볼 20%, 느린 공 16%, 슬라이스 12%, 백핸드 20% | ±0.476 |
| 서브 | 20% | 플랫 20%, 슬라이스 25%, 킥 20%, 세컨드 안정성 35% | ±0.340 |
| 리턴 | 18% | 퍼스트 대응 30%, 세컨드 대응 25%, 코스 25%, 준비·예측 20% | ±0.306 |
| 네트 | 16% | 기본 발리 30%, 낮은 발리 25%, 스매시 20%, 전진·포칭 25% | ±0.272 |
| 운영 | 18% | 범실 관리 30%, 상대 분석 25%, 압박 대응 25%, 위치·커버 20% | ±0.306 |

세컨드 서브 안정성과 백핸드, 범실 관리 등을 더 반영합니다. 퍼스트 서브는 단순 성공률 대신 속도·회전·코스를 유지한 성공과 압박 상황을 질문합니다. 넣기만 하는 서브로 최고 단계가 산출되지 않도록 했습니다. 문항·선택지는 src/data/questions.js, 계수는 CONFIG에서 수정할 수 있습니다.

## 운동배경과 활동량

운동은 보조 근거이므로 기존 전체 −0.30~+0.50 제한을 유지합니다.

타 종목 선수 = max(0, 단계점수 × 유사도 + 경력기간가감) × 은퇴감쇠.

라켓 단계점수 0.15/0.25/0.35/0.45/0.50, 구기 0.05/0.10/0.15/0.20/0.25, 기타 0.05/0.05/0.10/0.15/0.20. 정구 100%, 배드민턴·스쿼시 80%, 탁구 60%. 경력 1년 미만 −0.05, 1~2년 0, 3~5년 +0.05, 6년 이상 +0.10. 은퇴 5년 이내 100%, 10년 이내 90%, 20년 이내 80%, 이후 70%.

테니스 선수경력 6년 이상 +0.10, 1년 미만 −0.05(무대회만). 일반 스포츠 0/0.02/0.04/0.06, 체력운동 0/0.02/0.04/0.06. 최근 테니스 빈도 −0.10/0/0.05/0.10, 게임 −0.05/0/0.05/0.10. 실제 공백 5년 이상 −0.10, 10년 이상 −0.20, 20년 이상 −0.25.

## 결과·확장

최종 = Base + 수행 + 배경, 하한 1.0. 7.5는 상한이 아니라 선수급 시작점이며 그 이상을 허용합니다. MVP의 극단 입력 처리용 기술적 상한은 CONFIG.maxSurvey=9.0입니다. 초등 무대회 상한 5.5는 별도 적용합니다. 내부 정밀도를 유지하고 표시만 2자리 반올림, 공개는 0.5 단위 반올림합니다. 표시 합계는 0.01 차이가 날 수 있습니다.

신뢰도는 자가 입력 근거 강도이며 정확도 확률이 아닙니다. 모든 결과는 provisional, 모든 대회는 아직 미인증입니다. 결과 객체는 schemaVersion, scaleId, algorithmVersion, input, rating, publicGrade, status, verifiedMatches, history를 포함합니다. 향후 인증 경기(id, playedAt, opponentRating, score, format, verification, ratingBefore/After)와 별도 갱신 함수를 추가할 수 있습니다. 현재 저장·인증·경기 갱신은 미구현입니다.

지원 브라우저에 읽기 전용 WebMCP read_ktrp_result 도구를 등록합니다. 지원 환경의 등록·실행 검증은 미완료입니다.

## 0.4 문항 개편

스트로크는 공의 높이·속도·공격 기회·슬라이스 활용·백핸드 타점 선택을 분리합니다. 서브는 플랫/슬라이스/킥/세컨드 안정성을 개별 평가합니다. 구질 구사 여부만으로 최고점을 주지 않고 반복 성공·코스 조절·압박 상황 적용으로 단계를 나눕니다. 문항 수는 22개이며 수행능력 총 보정폭은 그대로입니다. 기존 20개 원응답과 호환되지 않으므로 새 설문 응답이 필요합니다.

## 0.5 대회 종류·참가 규모

지도자부·실업선출 대회를 별도 Base로 추가했습니다. 새 앵커는 MVP 설계값이며 대회 명칭 자체가 선수경력 인증을 의미하지 않습니다. 선수경력 Base와 대회 Base는 중복 가산하지 않습니다. 참가 규모는 16/32/48/64/96팀 이상이며 계산 함수도 이 5개 값만 허용합니다. 96 이상 구간은 동일 점수, 결과 상위 비율은 96팀 기준 근사치(실제 비율은 표시값 이하)입니다. 원입력에서 실제 참가팀 수는 보존하지 않으며 tournament.teamsAtLeast=true로 구간을 구분합니다.

## 0.6 최종 패배 경기 스코어 보정

테린이·지역 신인부·전국 신인부의 본선 탈락 기록(본선 첫 경기, 64강~준우승)에 선택적으로 최종 패배 스코어를 입력합니다. 우승·예선 탈락·오픈부·지도자부·실업선출 대회에는 적용하지 않습니다. 스코어 미상·기권·중단·부전패는 보정 0이며 가상의 스코어를 넣지 않습니다. MVP는 정상 종료된 단일 세트 또는 프로세트 게임 수만 처리합니다. 다세트 경기·타이브레이크 포인트는 입력하지 않습니다.

스코어 보정 = −0.50 × (1 − 내 게임 수 / 상대 게임 수). 최대 감점은 CONFIG.lossScore.maxDeduction, 대상 유형은 CONFIG.lossScore.types에서 변경합니다. 5–6은 −0.0833…, 0–6은 −0.50. 지역 신인부 48팀 16강 Base 3.50, 중립 수행·배경 0 기준 각각 3.42P와 3.00P입니다. 상대 레이팅이 없는 상태의 보수적인 MVP 감점 정책이며 상대 실력 보정이나 검증된 경기 기반 모델은 아닙니다.

최종 = Base + 수행 + 배경 + 스코어 보정. 문항별 설문 점수는 종전대로 유지하며 낮은 설문 점수에 대한 특별 감점은 추가하지 않습니다. finish=-1은 본선 첫 경기에서 몇 강인지 모르는 경우이며 진출 비율은 미확인으로 표시합니다. 이 경우 Base는 전체 참가팀 수를 활용한 보수적 진출 단계값으로 계산합니다. 결과 scoreAdjustment와 tournament.lossScore에 스코어·보정값을 기록합니다.

대회 미경험 선택 시 구력·자기평가 기반 측정의 정확도가 낮고 실제 경기력과 다를 수 있다는 안내를 표시합니다. 잠정 등급(P)을 참고용으로 활용하도록 안내하며 계산 점수는 변경하지 않습니다.

## 여성 대회 부서 표시

대회 선택과 결과에 지역 신인부(개나리부), 전국 신인부(개나리부), 오픈부(국화부)로 표시합니다. 개나리부는 해당 지역/전국 신인부 Base, 국화부는 오픈부 Base를 사용하는 MVP 매핑입니다. 공식 대회 부서 간 실력 동등성이 검증된 환산은 아니며 현재 대회 계산값과 스코어 보정 대상은 유지합니다.

결과 화면에 남녀·대회 부서 간 점수 비교 안내를 표시합니다. 같은 점수가 동일 경기력을 의미하지 않으며, 신인부/개나리부·오픈부/국화부의 공통 Base 매핑은 미검증임을 안내합니다. 계산에는 영향을 주지 않습니다.

## 0.7 국화부 별도 계산

대회 선택에서 오픈부, 국화부를 분리합니다. 국화부는 64팀 16강 Base 4.80, 성적계수 0.30, 규모계수 0.14이며 **우승 Base는 모든 참가 규모에서 6.00으로 고정**합니다. 우승 정책은 tournaments.chrysanthemum.winnerBase로 관리합니다. 64팀 준우승은 5.70입니다.


위 수치는 대회 Base이며 최종 평점에는 수행 ±0.50와 배경 −0.30~+0.50가 별도로 반영되어 범위를 벗어날 수 있습니다. 예를 들어 국화 우승 Base 6.00에 최고 수행 +0.50이면 배경 0 기준 최종 6.50입니다. 새 부서는 기존 신인부 패배 스코어 감점 대상에 포함하지 않습니다. 공통 남녀 실력 환산이 검증된 값이 아니라 사용자 요청에 따른 MVP 초기값입니다. 과거 문서의 오픈부/국화부 공통 Base 설명은 이 버전에서 대체합니다.

## 0.8 개나리부 별도 계산

지역·전국 개나리부를 지역·전국 신인부에서 분리했습니다. 지역 개나리부 48팀 16강 Base 3.00(기존 지역 신인부 대비 −0.50), 전국 개나리부 96팀 이상 16강 Base 3.50(전국 신인부 대비 −1.00)입니다. 성적계수 0.25와 기존 규모계수(지역 0.14/전국 0.10)는 유지합니다. 전국 개나리부 96팀 이상은 16강 3.50, 8강 3.75, 4강 4.00, 준우승 4.25, 우승 4.50입니다. 최종에는 수행·배경·패배 스코어 보정이 적용됩니다.

기존 신인부 Base는 유지합니다. 개나리부도 본선 패배 스코어 보정 대상에 포함합니다. 성별 자체에 일괄 감점을 주는 것이 아닌 대회 유형별 초기값 조정이며 검증된 남녀 공통 실력 환산은 아닙니다. 과거 문서의 신인부/개나리부 공통 Base 안내는 이 버전에서 대체합니다.

슈퍼 국화부는 대회 선택·계산 기준·결과표에서 삭제했습니다. 국화부 우승 Base 6.00은 유지합니다.


## 0.9.0 선수경력 기준 개편 (현재 적용)

이 절은 이전 버전의 선출 기준점·초등 상한·대회 우선 설명을 대체합니다.
선출 기준점은 초등 5.0, 중등 5.75, 고등 6.5, 대학 7.0, 실업·프로 7.5입니다.
이는 검증 전 KTRP 정책값이며 커뮤니티에서 입증한 환산값이 아닙니다.
초등 선출의 5.5 상한을 제거했습니다. 전체 설문 계산 범위는 1.0~9.0입니다.

선수경력 Base = 단계 기준점 + 선수기간 보정 + 은퇴 후 운동 지속 보정.
선수기간은 1년 미만 −0.40, 6년 이상 +0.10, 나머지 0입니다.
은퇴 후 테니스 지속 +0.20, 다른 운동·체력운동만 지속 −0.30,
대부분 운동 중단 −0.70, 미응답·불확실 0입니다.
이 값에 min(은퇴 후 연수 / 5, 1)을 곱하며 현역은 0입니다.
운동 지속은 은퇴 이후 전반적 상태이며 최근 3개월 활동량과 구분합니다.
선수경력 보정은 Base에 포함하므로 일반 운동배경의 −0.30~+0.50 제한과 별개입니다.
실제 테니스 공백은 기존 운동배경 항목에서 별도 반영합니다.

선출의 대회 기록이 있으면 조정된 선수경력 Base와 대회 Base 중 높은 값을 사용합니다.
선수경력 Base를 사용하는 경우 낮은 부서 대회의 패배 스코어 감점은 제외합니다.
대회 경험자의 수행능력 보정폭은 기존 ±0.50을 유지합니다.
단일 대회로 선출 점수가 급락하는 것을 방지하는 잠정 정책이며,
향후 반복된 인증 경기 결과로 낮아진 현재 실력도 재평가해야 합니다.
결과의 formerPlayer, tournamentBase, recordUsed에 선택 근거를 저장합니다.

실행은 `npm start`, 테스트는 `npm test`, 배포 파일 재생성은 `npm run build`입니다.

## 결과 이미지 저장과 모바일 화면

결과 화면의 **결과 이미지 만들기**를 누르면 1080×2400 PNG를 생성합니다.
휴대폰 세로 기준 가로:세로 **9:20**이며 미리보기와 저장 파일은 같은 이미지입니다.
카드에는 내부 점수, 공개 등급, Base, 수행·운동·스코어 보정, 신뢰도,
대회 기록과 잠정 등급 안내를 담습니다. 상세 설문 응답은 웹 화면에서 확인합니다.
외부 이미지나 캡처 라이브러리 없이 `src/ui/export-image.js`의 Canvas로 생성합니다.

파일 공유를 지원하는 브라우저에서는 **공유 · 이미지 저장**을 누른 뒤
아이폰 공유 메뉴에서 이미지 저장을 선택할 수 있습니다.
파일 공유는 HTTPS 또는 localhost 및 브라우저 지원이 필요합니다.
공유 미지원 시 **PNG 다운로드** 또는 미리보기 길게 누르기로 저장합니다.
사진 보관함에 자동 저장하는 방식은 아닙니다.

390×844 모바일 브라우저에서 결과 UI의 가로 넘침이 없는 것과
PNG 미리보기의 실제 크기 1080×2400을 확인했습니다.
실제 iOS 공유 메뉴와 사진 앱 저장은 기기에서 추가 확인해야 합니다.
